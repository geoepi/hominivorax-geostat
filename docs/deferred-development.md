# Deferred development roadmap

This work is intentionally outside the workflow-consolidation baseline.

- Scientific interpretation of production fixed effects, random effects, SPDE ranges, temporal structure, maps, and RPI.
- Publication graphics, manuscript tables, and final map styling.
- Default versus prior-fit theta comparison studies for runtime and convergence.
- Tier 1 thinning-off experiments and local-clustering alternatives: nearest-neighbor distance RW1, local-density/kernel effects, and multi-scale spatial structures.
- Sensitivity analysis around the current 14.5 °C physiological mask and
  alternative threshold specifications.
- Future minimization of retained Stage 1/2 source-derived fields and updates
  to model inputs that require a new scientific acceptance cycle.

The intended physiological flow is `raw statistical potential abundance → optional external physiological temperature constraint → temperature-constrained potential abundance`; raw statistical predictions must never be overwritten.
