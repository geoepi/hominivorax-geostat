# Preferential Sampling  
Spatiotemporal analysis of NWS detections to quantify sampling bias and correlative structure  

  
## Contents:  
1. [study_domain](https://github.com/geoepi/NWScrewworm/blob/main/elements/preferential_sampling/study_domain.md): Propose study area boundaries, create grids and polygons.  
2. [nws_observations](https://github.com/geoepi/NWScrewworm/blob/main/elements/preferential_sampling/nws_observations.md): Clean and combine raw NWS data from Excel files.   
3. [single_month_lgcppf](https://github.com/geoepi/NWScrewworm/blob/main/elements/preferential_sampling/single_month_lgcppf.md): Point model to estimate NWS detection intensity (i.e. number of cases per km$^2$). This is a test model showing a single time step.  
4. [temporal_lgcppf](https://github.com/geoepi/NWScrewworm/blob/main/elements/preferential_sampling/temporal_lgcppf.md): Point model to estimate NWS detection intensity.  This version models a 26-week period in weekly time steps.  
5. [lgcp_estimates_full](https://github.com/geoepi/NWScrewworm/blob/main/elements/preferential_sampling/lgcp_estimates_full.md): Inspect and evaluate model results.
